# Shopify Produktseiten-Challenge 🚀  

## 📌 Überblick  
Dieses Projekt ist die Umsetzung einer individuellen **Produktseite für Shopify**, basierend auf dem **Dawn-Theme**.  
Ziel war es, die Produktseite **pixelgenau** nach Design-Vorgabe umzusetzen und mit **Shopify Liquid, CSS & JavaScript** interaktiv zu machen.  

## ✅ Features  
✔ **Produktdaten dynamisch aus Shopify Liquid**  
✔ **Interaktive Komponenten:** Bildergalerie, Variantenauswahl, Wishlist  
✔ **Sticky ATC-Bar**, die erscheint, wenn der Warenkorb-Button aus dem Viewport verschwindet  
✔ **Express-Badge & Gutschein-Funktion** steuerbar über den Theme-Editor  
✔ **Versand- und Rückgabeinfos als Drawer**  
✔ **Responsive Design für Mobile, Tablet & Desktop**  

## 🚀 Technologien  
- **Shopify Liquid** für dynamische Produktinfos  
- **SCSS/CSS** für das Styling  
- **Vanilla JavaScript** für Interaktivität  
- **GitHub** zur Versionskontrolle  

## 💡 Herausforderungen  
- **Shopify's Theme-Editor & API waren nicht immer intuitiv**  
- **Best Practices aus React.js sind oft nicht übertragbar**  
- **Design war teils inkonsistent, was viele Tests erfordert hat**
